# ANVAYA 🏛️

**Post-Award Intelligence for Public Works**

Anvaya solves a critical problem in public infrastructure and government procurement. Public contracts are carefully evaluated before they are awarded, but after award, projects often experience material drift: contractors change, specifications downgrade, timelines slip, and costs increase.

Anvaya provides deterministic gap analysis—automatically parsing contracts, invoices, variation orders, and inspection reports to compare the **Award Snapshot** with the **Current Facts**.

## Key Features

- 🔍 **Deterministic Gap Analysis:** Automatically flags variations in Cost, Schedule, and Quality.
- ⚡ **Intelligence Command Center:** A beautiful, Apple-inspired, minimalist dashboard to monitor at-risk projects globally.
- 🛡️ **Evidence Verification:** Traces project variations back to their supporting documents (or flags when evidence is missing).
- 📈 **Alignment Scoring:** Instantly see how far a project has drifted from its original approved state.

## Tech Stack

- **Framework:** Next.js 16 (App Router)
- **Styling:** Tailwind CSS v4
- **Animations:** Framer Motion
- **Icons:** Lucide React
- **Typography:** Inter (System Stack)

## Getting Started

1. Clone the repository
2. Install dependencies:
```bash
npm install
```
3. Run the development server:
```bash
npm run dev
```
4. Open [http://localhost:3000](http://localhost:3000) with your browser.

## Philosophy

"Remove everything that does not add value." 
The UI is designed to feel like a premium intelligence tool, not a generic SaaS dashboard. We rely on clean typography, precise whitespace, and subtle interactions to present complex post-award data clearly.
